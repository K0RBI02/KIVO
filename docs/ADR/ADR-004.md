# ADR-004

## Titel

Benutzerdaten und Engine-Daten sind getrennt.


## Entscheidung

Ein Entry enthält ausschließlich Nutzerdaten.

Die Analysis enthält ausschließlich
berechnete Informationen.

Die Analysis darf jederzeit gelöscht
und neu berechnet werden.


Entry

- ID
- Titel
- Inhalt
- LastModified
- Links


Analysis

- Keywords
- Relations
- Statistics
- Metadata
