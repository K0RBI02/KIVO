# ADR-006

## Titel

Ranking


## Entscheidung

Die Gewichtung der Suche erfolgt nach folgender Priorität:


1.

Titel + Inhalt


2.

Erkannte Begriffe


3.

Fuzzy Matching


4.

Synonyme


5.

Manuelle Verknüpfungen


6.

Benutzerverhalten


7.

Aktualität


## Hinweise

Benutzerverhalten dient ausschließlich
als Bonus.

Es darf niemals einen inhaltlich besseren Treffer
überholen.

Die Qualität des Inhalts
hat immer Vorrang.
