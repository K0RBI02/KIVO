# ADR-001

## Titel

Die Wissens-Engine ist das Produkt.


## Entscheidung

Alle Geschäftslogik befindet sich ausschließlich in der Engine.

Clients besitzen keinerlei Entscheidungslogik.


## Begründung

Dadurch können beliebig viele Clients
auf dieselbe Engine zugreifen.

Neue Clients benötigen keine Anpassungen
an der Kernlogik.
