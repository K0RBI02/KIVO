# ADR-005

## Titel

Self Discovery


## Entscheidung

Die Engine besitzt möglichst wenig eingebautes Wissen.

Sie lernt Begriffe,
Zusammenhänge und Beziehungen
aus den Einträgen des Nutzers.


## Begründung

IT verändert sich ständig.

Neue Technologien entstehen laufend.

Die Engine soll diese automatisch entdecken,
anstatt auf eine riesige statische Wissensdatenbank angewiesen zu sein.
